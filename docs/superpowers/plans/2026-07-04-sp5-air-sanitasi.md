## Global Constraints

- Spec: [2026-07-04-sp5-air-sanitasi-design.md](../specs/2026-07-04-sp5-air-sanitasi-design.md). Reuse: SP4 electrical pattern verbatim (entity→store→auto-gen→sheet→sheet-list→editor→AI→RAB), `Drawing` contract (lines only; kinds `outline|slab|opening|ground|cut`; labels `room|level|title`), `sheet-list.ts` `SheetListEntry.build(layout,interiors,cuts)`, `ceiling-plan.ts`/`electrical-plan.ts` symbol style (`kind:"opening"`, `round2`, bbox/dims SEMUA ruang), gate Playwright FULL.
- **Koordinat:** `WaterPoint.x/y` = meter ABSOLUT (ruang koordinat, y-UP). `SanitationObject.x/y` = meter ABSOLUT di LAHAN (Site.widthM×depthM).
- **Tipe titik air** `WaterPointType` = `"kloset"|"wastafel"|"shower"|"kran"|"kran_taman"|"floor_drain"|"sink_dapur"|"kran_wudhu"`. **Sistem** `WaterSystem`: kloset→`"limbah"`; wastafel/shower/floor_drain/sink_dapur→`"kotor"`; kran/kran_taman/kran_wudhu→`"bersih"`. `WATER_SYSTEM: Record<WaterPointType, WaterSystem>` dipatok.
- **Label** `WATER_POINT_TYPES: Record<WaterPointType,string>`: Kloset · Wastafel · Shower · Kran · Kran Taman · Floor Drain · Sink Dapur · Kran Wudhu.
- **WATER_DEFAULTS** `Record<RoomType, WaterPointType[]>`: `kamar_mandi ["kloset","wastafel","shower","floor_drain"]` · `dapur ["sink_dapur","floor_drain"]` · `laundry ["kran","floor_drain"]` · `taman ["kran_taman"]` · `musholla ["kran_wudhu"]` · sisanya `[]`. Fallback `[]`. Penempatan sepanjang dinding bawah (offset `WALL_OFFSET_M=0.3`), pola SP4 `autoGenerateElectrical`.
- **Pipa (Ø, SNI 8153:2015)** `PIPE_DIAMETER: Record<WaterSystem,string>`: `bersih "¾\""` · `kotor "2\""` · `limbah "4\""`; vent `"2\""`. (kloset limbah 4″; grey 2″; supply ¾″.)
- **Penghuni:** `occupantsOf(layout) = Math.max(4, bedroomCount * 2)`, `bedroomCount = layout.rooms.filter(r=>r.type==="kamar_tidur").length`.
- **Septic (SNI 2398:2017 pendekatan):** `Q_L = occupants * 150`; `Vww = Q_L * 3 / 1000`; `Vsludge = occupants * 30 * 3 / 1000`; `V = round2(Vww + Vsludge)` m³. Kedalaman air 1,5 m; `A = V/1.5`; `W = round2(Math.sqrt(A/2))`, `L = round2(2*W)`; `depthM = 1.8`. `capacity = V`. Contoh 8 penghuni: Q 1200, Vww 3.6, Vsludge 0.72, V 4.32, A 2.88, W 1.2, L 2.4.
- **Sumur resapan (SNI 8456 pendekatan):** input `roofArea` (rumus SP3: datar `footprint*1.1`, miring `footprint*(1/cos slope)*1.15`, footprint=`site.widthM*site.depthM`). `Vr = round2(roofArea * 0.05)` m³; `H = 2.0`; `D = clamp(round2(Math.sqrt(4*Vr/(Math.PI*H))), 0.8, 1.4)`; objek `widthM=lengthM=D`, `depthM=H`, `capacity=Vr`. Contoh roofArea 70,4 → Vr 3.52, D=clamp(√(14.08/6.283)=1.497→1.4).
- **Bak kontrol:** ukuran `0.4×0.4×0.5` m (`widthM=lengthM=0.4, depthM=0.5`). Jumlah = `wetRoomCount + 1` (wetRoom = ruang dgn WATER_DEFAULTS berisi tipe sistem `kotor|limbah`) — 1 per ruang basah + 1 di dekat septic.
- **Auto-posisi default (auto-size):** septic di halaman belakang `x=site.widthM*0.25, y=site.depthM - L/2 - 0.5`; resapan `x=site.widthM*0.75, y=site.depthM - D/2 - 0.5`; bak kontrol disebar `x = site.widthM*(i+1)/(n+1), y=site.depthM-0.6`. Semua bisa digeser (clamp ke lahan).
- **Simbol titik air** (semua `kind:"opening"`, `round2`, half `SYM_M=0.15`): jumlah garis dipatok — `kloset` 6 · `wastafel` 4 · `shower` 5 · `kran`/`kran_taman`/`kran_wudhu` 3 · `floor_drain` 6 · `sink_dapur` 5. Lampu/electrical tak disentuh.
- **Jalur pipa (plumbing-plan):** per lantai 1 titik "stack" (sudut ruang basah pertama); tiap fixture → garis ortogonal 2-segmen (`kind:"opening"`) ke stack; sistem dibedakan lewat legenda (bukan gaya garis — Drawing tak punya style). 
- **Disclaimer SNI wajib** (DrawLabel `kind:"room"`) di tiap sheet perhitungan (Detail Septic/Resapan/Bak): `"Perhitungan pendekatan berbasis SNI disederhanakan — wajib diverifikasi ahli plumbing/sanitasi berlisensi sebelum konstruksi."`
- **Sheet order:** setelah `electrical` (E-), sebelum `roof-detail` (terakhir): `plumbing` P-01.. per lantai (`plumbing-<floorId>`) → `riser` P-R (`riser`) → `sanitation-detail` S-01/02/03 (`sanitation-septic`/`sanitation-soakwell`/`sanitation-control`). `SheetKind += "plumbing"|"riser"|"sanitation-detail"`.
- Bahasa UI; tanpa dep baru; JSONB (tanpa migrasi); AI parity WAJIB; **a11y aria-label** pada tiap Select/Input (gate a11y akan tangkap, pelajaran SP4); build gate `npx next build` langsung; jangan chain `rtk vitest`+`npx vitest`.
