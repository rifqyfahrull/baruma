AI Renderer: dari preview 3D ke foto & video realistik

Perbandingan biaya, kualitas, dan trade-off penyedia AI pihak ketiga untuk mengubah screenshot low-poly three.js menjadi render fotorealistik yang konsisten dengan geometri — plus rekomendasi arsitektur integrasi untuk monolith Next.js Baruma.

Rekomendasi ringkas

  1. Bangun sendiri di atas fal.ai + Gemini API, bukan layanan arch-viz turnkey. Hampir semua tool arch-viz (Veras, PromeAI, D5, SketchUp Diffusion) tidak punya API publik yang layak untuk SaaS.
  2. Gambar — dua mode: mode Cepat pakai Google Nano Banana 2 (≈$0.067/gambar, <5 dtk); mode Presisi/HD pakai FLUX Depth/Canny via fal.ai (≈$0.03–0.05) dengan depth & edge map eksak dari canvas three.js — jaminan geometri 1:1 yang tak dimiliki kompetitor.
  3. Video — add-on premium: Kling 2.5 Turbo / 3.0 via fal.ai ($0.35–0.90 per klip 5–8 dtk) sebagai standar; Veo 3.1 Fast ($0.80–1.20) untuk tier atas. Sambung segmen dengan teknik first/last-frame.
  4. HPP ≈ Rp160–800/render → jual sebagai kredit Rp1.500–3.000 (margin >10×, norma industri). Video Rp8–14rb/klip.
  5. Backend tanpa worker baru: queue sudah ada di sisi provider (queue.fal.run) — cukup row Postgres + webhook + polling + cron rekonsiliasi. Hasil ke storage S3-compatible yang sudah ada (src/lib/server/storage.ts).

01Kenapa Baruma siap untuk fitur ini

Analisa kode + konfirmasi dari sesi pengembangan yang sedang berjalan menunjukkan fondasinya sudah ada:

Input pipeline

Paket Foto Presentasi

src/lib/three/photo-package.ts sudah memotret 4 sudut (iso/depan/atas, siang/senja) via Screenshot Bridge — tinggal jadi sumber input AI Renderer.

Keunggulan unik

Scene 3D asli, bukan foto

Depth, normal, edge, dan segmentation map bisa diekspor eksak dari geometri three.js — kompetitor harus menebaknya dari gambar RGB.

Monetisasi

Sistem kredit sudah jalan

Entitlements per plan (creditsPerPeriod) + billing Mayar + admin backoffice — AI render tinggal jadi konsumen kredit baru.

Filosofi produk

Memang direncanakan

Prinsip produk: render 3D internal tetap low-poly grammar-first; realisme datang lewat integrasi AI image/video — fitur ini adalah jalur itu.

04Kenapa bukan layanan arch-viz turnkey

Layanan khusus arsitektur (Veras, ArchiVinci, PromeAI, SketchUp Diffusion, D5, Lumion) hampir semuanya aplikasi end-user atau plugin CAD tanpa API publik. Pengecualian yang punya API: MyArchitectAI ($0.03/render, video $0.25 — turnkey termurah tapi vendor kecil, tanpa input depth) dan Spacely AI (enterprise API, nego sales — vendor Asia Tenggara, menarik untuk partnership interior). Keduanya hanya menerima RGB, sehingga kalah akurat dibanding jalur "model generik + depth buffer asli dari three.js" yang bisa Baruma bangun sendiri.

05Benchmark kompetitor & harga jual

Teknologi standar industri terkonfirmasi publik: Stable Diffusion/FLUX + ControlNet (Planner 5D, Collov, RoomGPT). Coohom (AIHom) dan Interior AI eksplisit menerima screenshot 3D sebagai input — memvalidasi use case Baruma.

06Arsitektur teknis yang disarankan

Pipeline render

Canvas R3F (Paket Foto sudah ada)
  ├─ beauty pass (screenshot RGB)
  ├─ depth pass    — MeshDepthMaterial override, dilinearisasi & invert (gaya MiDaS)
  ├─ edge pass     — Sobel atas depth+normal (lebih bersih dari canny utk low-poly)
  └─ seg pass      — MeshBasicMaterial per kategori, palet ADE20K (opsional, SDXL)
        │
        ▼
POST /api/v1/renders  →  row Postgres status='queued'
        │                 + prompt compiler: scene graph → daftar material
        ▼                   per permukaan + preset gaya + seed terkunci
queue.fal.run (FLUX Depth / Nano Banana)  ← antrian di sisi provider
        │  webhook (verifikasi signature) + cron rekonsiliasi tiap menit
        ▼
unduh hasil → storage S3-compatible (sudah ada) → update row
        │
        ▼
klien polling GET /api/v1/renders/:id tiap 2–3 dtk → galeri hasil

Keputusan kunci

Konsistensi

Prompt compiler, bukan prompt user

Scene graph dikompilasi deterministik jadi daftar material per permukaan + preset gaya server-side. User memilih preset ("Tropis Sore", "Golden Hour"), tidak menulis prompt.

Multi-view

Referensi berantai

View #1 via FLUX Depth → view berikutnya via Nano Banana Pro (s.d. 14 referensi) dengan hasil view #1 sebagai acuan material. Simpan seed + prompt + URL referensi di row proyek.

Tanpa Redis

Queue di provider

Tidak perlu worker terpisah — sesuai prinsip monolith. Jika kelak butuh antrian lokal (retry, fan-out), pakai pg-boss (di atas Postgres), bukan BullMQ.

Bundle

Nol dependensi berat baru

Pass depth/edge hanya berjalan saat tombol ditekan (bukan per-frame), memakai three.js yang sudah ada — baseline bundle route preview aman.

09Roadmap yang disarankan

Fase 1 · validasi

Prototipe murah

Uji di Replicate ($0.008/run) + AI Studio free tier: screenshot Paket Foto → Nano Banana 2 & FLUX Depth, bandingkan konsistensi pada 5–10 rumah nyata dari template Baruma.

Fase 2 · MVP gambar

Mode Cepat + Presisi

Endpoint /api/v1/renders, prompt compiler, integrasi kredit/entitlements, galeri hasil di tab preview-3d. Watermark untuk free tier.

Fase 3 · multi-view

Paket Foto Realistik

4 bidikan Paket Foto di-render AI sekaligus dengan referensi berantai — upgrade langsung dari fitur yang sudah dikenal user.

Fase 4 · video

Orbit sinematik premium

Kling via fal.ai dari render still terbaik; klip 5–8 dtk; harga premium Rp8–14rb. Evaluasi Veo 3.1 Fast untuk tier atas.
